# Custom fonts

> **Requires** manual download of the font files

## Font Config folders

* System-wide folder : `/usr/share/fonts`
* User folder : `~/.local/share/fonts` (_not used here_)

Inside those folder, it's better to regroup a collection of fonts in a dedicated folder.

* If the collection has the same format (e.g. all fonts are Open Type fonts) then create the folder inside the folder named after the font type (e.g. `/usr/share/fonts/opentype/xxx`)
* Otherwise, create the folder directly in the font folder (e.g. `/usr/share/fonts/xxx`)

Name the collection folder with a distinctive name, e.g. with the publisher name. E.g. my collection of custom made font for reproducing the glyphes of vintage computer could be stored in `/usr/share/fonts/opentype/sporniket/nostalgia2` : the first sublevel (`sporniket`) for the publisher name, and the second sublevel (`nostalgia2`) as the family/collection name (I plan to have several font created into that family)
