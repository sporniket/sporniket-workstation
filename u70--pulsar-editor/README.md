# User configuration of Pulsar, a community-led, hyper-hackable text editor

## Extensions to install

### General IDE experience

* `busy-signal`
* `atom-ide-definitions` (should install `atom-ide-hyperclick` automatically)

> See https://medium.com/@sporniket.studio/taming-pulsar-the-community-led-hyper-hackable-text-editor-part-4-aaf352b4ca09

### C/C++

* `pulsar-ide-clangd`

This list will provide C/C++ code navigability (provided one install [clangd](https://clangd.llvm.org/), [compdb](https://github.com/Sarcasm/compdb).

> See https://medium.com/@sporniket.studio/taming-pulsar-the-community-led-hyper-hackable-text-editor-part-4-aaf352b4ca09
