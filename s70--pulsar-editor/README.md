# Pulsar, a community-led, hyper-hackable text editor

* [Home page](https://pulsar-edit.dev/)
* [Downloade page](https://pulsar-edit.dev/download/#linux)

## How to install

* Download the latest suitable package, e.g. for debian based Linux distributions, the package to download at the time of writing is located at `https://github.com/pulsar-edit/pulsar/releases/download/v1.131.1/Linux.pulsar_1.131.1_amd64.deb`
* Install with the package, e.g. `dpkg -i the_pulsar_package.deb`

## Complements

* A ctag generator : [universal ctags](https://ctags.io/) ; provide explorability with _Symbols View_ (`CTRL+R`)
